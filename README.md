# ASP.NET sample for Azure App Service

This is an ASP.NET MVC web app that you can deploy to Azure App Service using Git.

This code is the default MVC app as generated by
[Visual Studio](https://www.visualstudio.com/products/visual-studio-community-vs),
extended with Forms authentication and a Playwright + Reqnroll (Gherkin) test project.

To learn how to deploy this starter web app to App Service in a few minutes, go to
[Get started with web apps in Azure App Service](https://azure.microsoft.com/en-us/documentation/articles/app-service-web-get-started/).

## Projects

| Project | Description |
|---------|-------------|
| `aspnet-get-started` | ASP.NET MVC 4.8 app (login `admin` / `admin`) |
| `TestProjectDemo` | E2E tests: Playwright + xUnit + Reqnroll (Gherkin FR) |

## CI / CD

See **[docs/CI-CD.md](docs/CI-CD.md)** for GitHub Actions (build, tests, HTML report, GitHub Pages for reports, Azure deploy).

**Note:** GitHub Pages cannot host ASP.NET Framework 4.8. Use Azure App Service for the website; Pages is used only for the test report.
